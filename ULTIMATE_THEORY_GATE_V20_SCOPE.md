# Ultimate v20 approval scope

The final gate uses four distinct approval levels:

1. **Internal candidate** — anomaly/operator/software consistency survives the configured adversarial tests.
2. **Conditional benchmark** — extra universal/aligned/hierarchical portal assumptions define a numerically safe benchmark region.
3. **Full phenomenology** — requires unique UV-fixed fermion couplings, finite-model FCNC closure, and explicit matrix Yukawa RG with two-loop threshold closure.
4. **Empirical realization** — requires real conversion data; software injection recovery is not evidence.

The current expected result is approval of levels 1 and 2 only. Levels 3 and 4 must remain blocked unless their missing inputs are genuinely supplied and the fail-closed gate changes state without weakening any test.
